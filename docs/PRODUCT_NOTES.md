# aquant 产品思考整理

> 来源：项目根目录《新建 DOCX 文档.docx》中的手记，按产品工作环节归类整理。
> 标注「待补充」的部分是下一步要做的产品工作。

## 1. 目标用户

原始记录：

- 使用 PTrade 等平台的个人量化研究者
- 券商、私募或资管中的量化研究员
- 需要快速解释量化信号的投研助理

整理备注：

- 「投研助理」是产品形态（aquant 本身就是那个助理），不是用户群体；PRD 中用户应写前两类。
- 待补充：用户特征描述——资金规模、信号频率、每天看几份报告、现有工具链（PTrade 之外用什么看盘/查资料）。

## 2. 竞品初析

### 通用大模型（ChatGPT、Claude、Kimi 等）

- 优点：预设 prompt 解释量化信号，可以一定程度上快速解释、辨别信号。
- 缺点：流程相对固定，碰到预设外的量化信号缺乏分辨能力；无法判断市场情绪或行业风险。

### 金融信息平台（Wind、同花顺、东方财富）

- 原始记录仅提名，未展开分析。待补充：目标用户、核心功能、数据源、定价、优劣势。

### 待补充的第三类：AI 投研产品

- 同花顺 i 问财、慧博、妙想等 AI 研报/投研产品，以及各类 AI 投研创业项目。
- 最终产出：竞品对比表 + 差异化结论（aquant 的定位：本地优先 + 可审计证据 + 确定性计算层）。

## 3. 用户访谈提纲（已有 10 问，按主题归类）

### 工作流程类

1. 你现在收到 PTrade 信号后会做什么？
2. 研究一只信号内的股票需要查询哪些数据或资料？
3. 哪一步最耗时？
4. 什么情况下你会放弃研究这只股票？

### 信任类

5. 你最担心 AI 输出什么错误？

### 时效类

6. 一份报告距离量化信号出现多久生成才算可接受？

### 功能价值类

7. 目前除了统筹和量化信号 Agent 外，哪个在实际运行中实用性强？

### 安全与商业类

8. 是否允许公开资料发送给云端模型？
9. 哪些资料不能离开本地？
10. 你是否愿意为节省研究时间付费？

整理备注：问题质量较好，覆盖流程、信任、时效、价值、安全、商业六个维度。其中第 7 问（「哪个 Agent 实用」）预设了受访者了解产品，已移至体验后访谈。
已扩展为完整的两阶段访谈指南（未体验用户 / 体验后用户），见 [INTERVIEW_GUIDE.md](./INTERVIEW_GUIDE.md)。

## 4. Agent 产品协议（已实现）

原始记录要求每个 Agent 统一交付 8 项：

1. 做了什么
2. 得到了什么事实
3. 使用了哪些 Evidence
4. 存在哪些风险
5. 哪些内容未知
6. 是否需要其他 Agent 补查
7. 使用的 Prompt、模型和工作流版本
8. 耗时和成本

实现情况：已在项目中落地——`AgentContribution` / `EvidenceItem` / `risks` / `unknowns` 字段、统筹 Agent 的证据缺口追问循环、任务卡片上的配置/Prompt/工作流版本号、运行指标（耗时、Token、回退）。此项可作为 PRD 的「产品原则 / 非功能需求」章节。
