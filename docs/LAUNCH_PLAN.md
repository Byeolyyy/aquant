## 1. 现状与目标

**现状**：v0.1 桌面纵向切片已实现并可通过便携版分发给用户；首轮深度访谈完成 1/3–5 人；PRD 已按访谈回填至 v0.2，新增决策卡片（FR-9）等四项规划需求。

**本计划目标**（回答 PRODUCT_NOTES.md 缺口清单中「种子用户与上线计划」）：
1. 完成阶段二（体验后）访谈，验证产品价值
2. 种子用户 4–8 周真实使用，拿到可信/效率/付费三组验证数据
3. 跑通「效果证明」最小闭环（FR-12），为高价付费铺路
4. 产出 Go / No-Go 决策

## 2. 阶段二访谈执行计划

依据 [INTERVIEW_GUIDE.md](./INTERVIEW_GUIDE.md) 阶段二（18–29 问）：

- **对象**：首轮受访者回访（已建立信任，可对比「访谈前假设 vs 体验后态度」）+ 新招募体验用户，合计 3–5 人
- **方法**：任务观察法 + 出声思考，准备一份真实 PTrade 报告作为任务材料，只说「请把这份报告研究一遍，得出结论」
- **关键验证点**（访谈第 19/20/27 问是本次验证的核心）：
  - Q19 输出与人工结论一致性——不一致处即产品缺陷清单
  - Q20 「敢直接用它做决策吗」——信任建立的直接证据
  - Q27 体验后付费意愿与免费版构成——商业模式假设的首个实证

## 3. 种子用户招募

### 3.1 招募标准（画像 A，PRD 3.1）

- 使用 PTrade 等量化平台、信号驱动型策略
- T+1 复盘节奏（排除盘中抢筹型）
- 每天 3–10 只信号、单票手工研究 2–10 分钟
- 研究执行依赖东方财富免费功能，不为数据工具付费

### 3.2 渠道

| 渠道 | 依据 | 方式 |
|---|---|---|
| 量化博主付费社群 | 访谈 Q10：用户愿为博主知识付费 500–1,000 元/年——博主是他信任的对象 | 与 2–3 位量化博主合作：博主推荐 aquant 给社群成员，作为「社群福利」；后续可发展为分销渠道（与用户付费心智一致） |
| PTrade 用户社群（券商客户群、雪球量化版块） | 信号源所在社区 | 发帖招募 + 免费版体验邀请 |
| 首轮受访者的同类人 | 滚雪球 | 请受访者介绍 1–2 位同策略朋友 |

### 3.3 规模与周期

- 规模：5–10 人（个人量化研究者）；周期：4–8 周（效果证明期可延至 12 周）
- 激励：免费版全功能体验 + 定期回访（不给现金激励，避免招募到只为奖励的非目标用户）

## 4. 验证节奏（分三阶段）

### W1–2 上手期（对应阶段二访谈）

- 任务观察法记录：能否独立找到「解析并预览 → 启动研究」入口；是否理解 partial 校验；对 Agent 消息是否觉得乱；在哪些地方停顿/绕路（记录时间点）
- 产出：可用性缺陷清单 → 排序进入 v0.2 迭代

### W3–4 常规使用期

- 周活跃率、信号覆盖率（完成研究的信号数 / 用户当周信号总数）
- 单次研究时长 vs 人工基线（2–3 分钟/票）
- 决策卡片三态分布与采纳率：卡片提示与用户真实决策的一致性
- 幻觉抽查：随机抽取 10 次 Run，人工核对结论中每条事实是否可溯源

### W5–8 效果证明期

- 上线 FR-12 最小版（决策回填：一次点击 + 可选备注）
- 累计 20 次回填 → 输出第一份有效性报告草稿，与用户逐项核对归因（命中率提升归因于策略还是工具）
- 付费转化测试：以「年费 499–999 元」为锚点，测试购买意向与拒绝理由（**不实际收费**，用意向表达）

## 5. 成功判据（Go / No-Go）

### Go 条件（满足 ≥ 3 项）

1. ≥ 3/5 用户在 W3–4 连续 2 周使用，且对 Q20「敢直接采纳」给出肯定回答（含「部分采纳，仅复核风险项」）
2. 黄金评测集幻觉率 < 1%（评测集建设见 PRD 9.2）
3. 批量处理下平均单票耗时 ≤ 人工基线
4. ≥ 1 人表达付费意向（锚点 499–999 元/年）

### No-Go 触发（任一即停）

1. 0 人采纳卡片结论——说明「可信」没有转化为「可用」，回到访谈找原因
2. 核心用户反馈「不如我在东财自己查」——说明决策卡片六维设计失败，需重做信息架构
3. 幻觉率超标或出现编造数据事故——信任是产品生命线，先修机制再谈增长

**No-Go 不是失败**：面试叙事中它展示的是「验证驱动」的决策方式——数据不好就回炉，而不是硬推。

## 6. 风险与预案

| 风险 | 预案 |
|---|---|
| 迁移成本：用户离不开东财 7 步习惯 | 卡片对齐 7 步心智 + 每维可跳转东财验证（PRD FR-9.1）；宣传口径「帮你确认没漏掉利空」，而非「替代东财」 |
| 样本量小：每天 3–5 只信号，效果证明周期长 | 效果证明期放宽至 12 周；先用「时间节省 + 遗漏项找回」两个可快速验证的指标建立信心，命中率统计作为长期指标 |
| 妙想竞争压力（用户可能「用东财就行」） | 主打确定性计算与批量处理两个妙想没有的能力（竞品分析第 7 节）；不硬拼溯源 |
| 阶段二访谈招募不到目标用户 | 以首轮受访者回访为先；博主渠道作为主渠道推进，宁可慢不可错（错误用户给出错误结论） |

## 7. 面试叙事（迭代故事）

PRODUCT_NOTES.md 缺口清单最后一项：把现有功能叙述为「用户反馈驱动」的决策链。建议叙事：

### 7.1 一句话故事线

> 「我做了个多 Agent 量化研究工具，先用 4 个假设写了 PRD，然后访谈了一位真实的 PTrade 研究者——结果 3 个假设被推翻：他不缺时间（单票 2–3 分钟），不在意隐私（"都无所谓"），付费只认效果证明。于是我把定位从『省时间 + 本地优先』改成『不漏 + 可信 + 批量』，新增了决策卡片、观察池和效果证明三个需求，定价也改成锚定他真实掏过钱的价位。」

### 7.2 访谈驱动决策速查（面试问答素材）

| 面试官可能的追问 | 答案指向 |
|---|---|
| 「你的需求是拍脑袋的吗？」 | 不是——4 个假设、29 问提纲、真实访谈、3 个假设被证伪（PRD 2.3 对照表） |
| 「本地优先是你的卖点，用户说无所谓，你怎么看？」 | 卖点让位于用户真实焦虑（造假焦虑）；本地化保留为实现方式，机构线仍为卖点（PRD 8.1 注） |
| 「为什么不做交易/不做荐股？」 | 信任未建立前 AI 输出不接触资金；用户明确拒绝「AI 给方向」（PRD 6.2） |
| 「你怎么定价？」 | 不凭空定价——锚定用户真实付费行为（博主知识付费 500–1,000/年）+ 效果证明解锁高价档（PRD 第 10 章） |
| 「巨头（东财妙想）做了怎么办？」 | 妙想做选股、我做复盘；确定性计算与数据源中立是模型无关的护城河（竞品分析第 6、7 节） |

### 7.3 简历 bullet 建议

- 完成 28 分钟深度用户访谈并回填 PRD：推翻 3/4 项产品假设（耗时、隐私、定价），重构定位为「可验证真实 + 确定性计算」，新增决策卡片/观察池/批量处理三项需求
- 完成 6 类竞品分析（东财妙想/问财/慧博/Wind/通用大模型/PTrade 生态），识别妙想「100% 溯源」撞车风险，将差异化锚点从溯源转向确定性计算与数据源中立
- 基于用户真实付费行为（500–1,000 元/年博主知识付费）与效果证明意愿（3–5 万/年），设计免费→订阅→高阶三档商业模型与 FR-12 效果证明机制
