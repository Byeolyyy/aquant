## 1. 分析目标与结论先行

**结论先行**：aquant 最直接的竞品不是 Wind，而是「用户在东方财富上的手工 7 步流程」；最大的竞争威胁来自东方财富妙想（宣称「全程 100% 溯源」，与 aquant 原卖点直接撞车）。v0.1 的「本地优先 + 可审计证据 + 确定性计算层」定位在访谈与竞品调研后被修正为：

**报告级端到端自动化 + 确定性规则计算 + 数据源中立 + 人机协作边界**

---

## 2. 用户视角的选择逻辑（访谈还原）

竞品分析不应从产品出发，而应从用户的选择行为出发。从访谈可以还原目标用户的完整决策链：

| 用户行为 | 访谈依据 | 解读 |
|---|---|---|
| 7 步研究全部在东方财富完成，无跨平台跳转 | Q5 | 用户的「真竞品」是东财手工流程——迁移成本是习惯，不是价格 |
| 不为 Wind/iFinD 等数据工具付费 | Q10 | 数据终端虽权威，但不在目标用户付费心智内 |
| 通义千问做研报总结被彻底否定：「只会讲好东西」「存在假信息」「搞错重点」 | Q7 | 通用大模型在开放式内容生成场景已出局 |
| ChatGPT/Kimi 做量化方法论问答被接受：「有参考价值」 | Q9 | 结构化、可验证的问答是 AI 的信任边界 |
| 愿为博主知识付费 500–1,000 元/年 | Q10 | 付费逻辑：认可「人的洞察」，不认可「工具的数据」 |
| 信息需求：「现在也够了」，追求「更真」而非「更多」 | Q12 | 竞品的「信息全面」策略对此用户无效 |
| AI 不能「主动给出研究主题或方向」 | Q9 | 用户拒绝「AI 给方向」，只接受「人给方向 + AI 执行」 |

**推论**：任何主打「更多数据」「更全报告」「AI 荐股」的竞品，对这位用户都没有替代价值；能替代他的只有「更快完成那 7 步、且每步可验证」的产品。

## 3. 2026 年竞争格局

公开资料显示，2026 年初 AI 投研进入「能推理、能闭环」阶段，格局三分：

1. **券商闭环**：华泰 AI 涨乐等，AI 选股与自家交易账户打通
2. **行情终端查数**：同花顺问财、东方财富妙想，依托行情终端语料与数据
3. **第三方投研**：慧博等，以研报语料与机构服务见长

aquant 属于第四类狭缝：**研究执行工具**——不选股、不荐股、不交易，只把「信号复盘」这件具体的事自动化。这与用户「人给方向、AI 执行」的心智完全吻合。

## 4. 竞品逐一分析

### 4.1 东方财富手工流程 + 妙想 AI（最直接竞品 & 最大威胁）

**产品背景**：东方财富是用户现状工作流的承载平台（免费行情、资金排序、多股同列、大事、板块、K 线全部免费可用）。其 AI 产品线「妙想」演进：妙想投研助理（2024-11 发布，宣称「喝 1 杯咖啡的时间完成原本一天的工作」，覆盖智能问答、智能研报、研报总结、私域知识库、数据分析，宣称**全程 100% 溯源**）→ 妙想 Skills（2026-03，面向机构的技能包：股票筛选、宏观洞察、数据查询、资讯穿透、量化 API、妙想问答）→ 个人版六大炒股技能（2026-06，筹码结构、看 K 线、逃顶、尾盘低吸等）。

**优势**：
- 用户 7 步所需的全部免费功能已在东财生态内，迁移成本为零
- 数据、语料、账户三位一体：可与东财证券账户打通，形成「妙想选股 + 东财交易」闭环
- 溯源卖点与 aquant 撞车（「全程 100% 溯源」）
- 体量与品牌：妙想投研助理已服务近万家金融机构，入选 2025 WAIC SAIL 奖 TOP30

**差距（aquant 的机会）**：
- **不解析 PTrade 报告**：妙想/问财是选股与问答入口，不是「粘贴报告 → 完整研究」的工作流
- **无用户自身策略信号规则的确定性计算**：妙想是 LLM 推理，aquant 是代码判定（`all_conditions_met`、P1/P2/P3 归类），用户策略信号的关键数字不可能被模型算错
- **数据源绑定东财**：东财不会集成 Tushare/巨潮/Tavily 多源交叉
- **云端处理**：机构用户的数据外传顾虑（画像 B）无法满足
- **AI 荐股导向**：六大技能（逃顶、低吸）本质是「AI 给方向」，与目标用户「人给方向、AI 执行」心智相反

**威胁评估**：**高**。妙想若继续向「信号复盘工作流」延伸（如接入券商量化平台报告），将直接侵蚀 aquant 的 P0 场景。应对见第 7 节。

### 4.2 金融数据终端（Wind / iFinD / Choice）

- **定位**：机构级数据终端，数据权威、成体系
- **定价**：Wind 年费约 2–4 万/席
- **与 aquant 的差距**：只提供数据不提供结论；人工整理仍需大量时间；访谈确认目标用户（个人线）**明确不为数据工具付费**
- **关系**：非竞品，更接近「潜在数据源」。机构线（画像 B）用户是 Wind 用户，aquant 以「研究报告自动化 + 审计链」补充而非替代 Wind

### 4.3 同花顺问财

- **定位**：自然语言选股标杆，问财 2.0（2026 初）强化多 Agent 协同与慢思考推理，中文金融体验评分居前
- **优势**：条件组合灵活（市盈率、均线形态、主力净流入可写进同一指令）、跨券商、口语化语义理解
- **与 aquant 的差距**：场景错位——问财是「选股」，aquant 是「复盘已有信号」；问财不支持粘贴 PTrade 报告；交易需跳转券商
- **启示**：问财证明「自然语言 + 数据」已被巨头做透，aquant 不应做通用选股，应死守「报告级研究执行」细分

### 4.4 慧博投研

- **定位**：研报语料起家的智能投研（1,800 万份全球研报），AI 产品中心（中文/外文研报问答、公告问答、财报问答）、智能策略终端（机构向），2025-04 接入 DeepSeek，「生成推理结论并标注来源」；已与中信证券、中金公司合作打造投研智能体平台
- **优势**：研报深度语料与机构服务能力（数据处理、信息整合、报告生成三大模块）
- **与 aquant 的差距**：以研报为中心，非信号复盘工作流；机构向，个人线产品弱；用户的「盘后研报流」是其潜在场景——但用户已否定 AI 观点总结，aquant 若做盘后流，形态是「证据化抽取」而非慧博式问答/生成
- **启示**：慧博验证了「标注来源解决幻觉」是行业共识方向，aquant 的证据登记方向正确，但需守住「确定性计算」这一更硬的差异

### 4.5 通用大模型（ChatGPT / Claude / Kimi / DeepSeek / 通义千问）

- **用户实测结论（访谈）**：
  - ✅ 方法论问答（策略有效性评估等结构化问题）——「有参考价值」，已融入日常工作流
  - ❌ 研报总结——通义千问被否定：「只会讲好东西」「假信息」「搞错重点」
- **与 aquant 的差距**：无 PTrade 信号解析能力；无市场数据接入与证据登记；幻觉无约束；「AI 给方向」式输出不符合用户协作模式
- **关系**：既是竞品（零散查询场景）也是基础设施（aquant 的统筹模型可配置 OpenAI-compatible 接口）

### 4.6 PTrade 本身（上游生态，非竞品）

- PTrade（恒生电子）是券商端云端托管式量化交易终端，已在国内近 40 家券商上线，免费、10 万资产门槛，提供 Python 策略开发、回测、实盘执行
- 它是 aquant 的**信号来源**（用户报告来自 PTrade），不是竞品
- **潜在威胁**：恒生或券商若在 PTrade 内集成 AI 研究报告功能，将形成「平台自研」挤压。应对：aquant 保持数据源中立（不绑定单一券商/平台），与券商形成生态而非对抗

## 6. 差异化定位（v0.2 修订）

### 6.1 定位演变

| | v0.1 | 问题 | v0.2 |
|---|---|---|---|
| 三词定位 | 本地优先 + 可审计证据 + 确定性计算层 | 本地化被访谈证伪为非卖点；「溯源」被妙想撞车 | **报告级端到端自动化 + 确定性规则计算 + 数据源中立 + 人机协作边界** |

### 6.2 差异化金字塔（自上而下，越往下越难被复制）

1. **报告级端到端自动化**（体验层）：粘贴 PTrade 报告 → 结论 + 决策卡片。妙想/问财没有这个入口。
2. **确定性规则计算**（技术层）：用户策略信号规则由代码判定，模型不可修改名单、排序与数字。这是模型能力无关的护城河——大模型幻觉再低，也替代不了「代码不算错」。
3. **数据源中立**（生态层）：不绑定单一行情平台，多源交叉可验证。任何绑定东财/同花顺的巨头都做不了。
4. **人机协作边界**（心智层）：AI 只聚合不推荐。与「AI 荐股」主流叙事相反，但对目标用户（被 AI 骗过一次的人）是信任来源。

### 6.3 一句话差异化陈述（面试用）

> 「妙想和问财帮用户选股，aquant 帮用户**复盘**股——把『收到信号后那 2–3 分钟的 7 步手工操作』变成一次粘贴，且每一步都能点开来源验证。AI 在这里只负责聚合证据，不负责给方向。」

## 7. 竞争风险与应对

| 风险 | 可能性 | 应对 |
|---|---|---|
| 妙想向信号复盘工作流延伸（接入券商量化报告） | 高 | ① 死守 PTrade 适配深度：确定性规则库、逐 Run 稳定性统计、改名/退市身份识别，这些是 LLM 原生产品做不好的；② 机构线主打本地化（数据不出本机），妙想的云端架构无法跟进；③ 用黄金评测集做公开的幻觉率/溯源率对比 |
| 恒生/券商在 PTrade 内集成 AI 研究 | 中 | 数据源中立定位：aquant 跨券商、跨平台，不与任何单一券商绑定；转向与券商「生态合作」（如为券商客户提供增值客户端）而非对抗 |
| 大模型幻觉下降，使「可溯源」优势稀释 | 中 | 「确定性计算层」是模型无关的护城河；证据登记是产品体验而非模型能力；且妙想已有溯源，说明此赛道已无「独家」可言，必须靠组合差异而非单点差异 |
| 用户迁移成本（东财 7 步习惯） | 高 | 决策卡片刻意对齐东财 7 步心智（六维 = 7 步合并）；每维数据可跳转东财页面验证——**嵌入用户已有验证习惯，而非要求用户放弃东财**（访谈设计原则：降低迁移成本） |
| 「信息够用」导致产品无感知价值 | 中 | 主打「不漏」而非「更多」：风险 Agent 独立复核 + 观察池变化提示，讲「帮你确认没有漏掉利空」的故事 |

## 8. 对产品路线的直接影响（竞品分析 → 决策）

1. 决策卡片（FR-9）的六维必须**可跳转东财验证**——这是对抗迁移成本的关键设计，已写入 PRD。
2. 「溯源」不再是宣传重点（妙想已有），宣传重心转向**确定性计算**（「信号规则由代码判定，不是 AI 猜的」）与**批量处理**（「行情好时一次出 10 只信号，不再一只一只点」）。
3. 盘后研报流（访谈 P2 机会点）应避免与慧博正面竞争——形态锁定「证据化抽取 + 原文链接」，不做观点生成。
4. 效果证明（FR-12）必须做——这是妙想/问财都不提供的「策略有效性」数据，也是解锁高价付费（访谈 Q16）的前提。
